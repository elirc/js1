# Learning Paths

A TypeScript + React + Node + Postgres CRUD study scaffold for employee learning plans, mentors, budgets, and completion workflow.

## What it practices

- Shared TypeScript contracts in shared/types.ts
- Express routes with validation and parameterized Postgres queries
- Server-side search, status/category filters, sorting, and pagination
- Focused status mutation separate from full update
- Nested activity log records
- React controlled forms and typed API wrappers

No dependencies are installed; this is source for learning.
