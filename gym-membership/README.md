# Gym Membership

A more complex JavaScript CRUD learning app using a React client and Express server.

## What this project practices

- REST CRUD endpoints with Express
- Server-side search, filtering, sorting, pagination, and validation
- Status transition endpoint separate from full update
- Nested activity log endpoints per record
- React controlled forms and derived dashboard stats
- A small API wrapper layer instead of raw etch calls in components

## Project map

- server/server.js - Express API, in-memory repository, validation, stats, activity log
- client/src/api.js - client API functions
- client/src/App.jsx - React UI, filters, form state, selected record activity
- client/src/styles.css - practical dashboard styling

This is intentionally a study scaffold. No dependencies are installed in this folder.
