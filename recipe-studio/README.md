# Recipe Studio

A React + Node CRUD app for recipes with nested ingredient data.

## Learning goals

- Send arrays in JSON request bodies
- Normalize comma-separated user input into structured data
- Render nested lists in React
- Practice search over tags and ingredients
- Keep backend validation readable

## Stretch ideas

- Add recipe steps as a nested resource
- Add image URLs
- Add favorite and meal-plan views
- Replace comma-separated inputs with dynamic ingredient fields
