# Task Board CRUD

A vanilla JavaScript task manager for practicing:

- Creating records from a form
- Rendering cards from an array
- Updating existing records
- Deleting records
- Filtering and searching
- Persisting data with localStorage

Open `index.html` in a browser to run it.
