# Job Pipeline

A React + Node CRUD project for tracking job applications.

## Learning goals

- Model a business workflow with stages
- Use REST filters for stage and text search
- Render records as pipeline cards
- Practice date fields and notes
- Keep mutation logic explicit and easy to trace

## Stretch ideas

- Add activity notes as a nested resource
- Add optimistic updates in React
- Add authentication and per-user records
- Add server-side sorting
