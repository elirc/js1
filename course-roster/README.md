# Course Roster

A React + Node CRUD app for managing courses and student counts.

## Learning goals

- Build a CRUD API around a domain object
- Validate business rules, such as capacity not going below enrollment
- Use React controlled forms for create and update
- Practice derived values like available seats
- Keep UI code readable with small helper functions

## Stretch ideas

- Add a second resource for students
- Create an enrollment endpoint
- Add pagination to `/api/courses`
- Store records in SQLite or PostgreSQL
