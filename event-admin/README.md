# Event Admin

A React + Node CRUD project for managing events and capacity.

## Learning goals

- Validate date and capacity input
- Render server data with derived availability
- Practice update and delete flows
- Keep API and UI naming consistent
- Think through business rules before writing code

## Stretch ideas

- Add attendee registration endpoints
- Add conflict detection by date
- Add server-side sorting by event date
- Add a dashboard summary route
